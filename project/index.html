История

Git всё чаще встречался в учебе, на стажировках и хакатонах. Его знание уже воспринималось как базовый навык, а у меня в этой части был заметный пробел.

Когда в вузе появился недельный летний мини-курс по Git, я записался, чтобы наконец разобраться в нём системно.

По ходу курса стало понятно, что Git это не просто набор команд. Главное оказалось в том, какие задачи он решает в реальной разработке. Больше всего я оценил три вещи.

За что я оценил Git

Не бояться ошибок

git revert позволяет отменить уже зафиксированное изменение, сохранив историю проекта.

Работать вместе

Ветки и merge позволяют нескольким разработчикам независимо менять проект и объединять результат.

Делиться кодом

Удалённые репозитории позволяют публиковать проект, получать чужие изменения и синхронизировать свою работу.
